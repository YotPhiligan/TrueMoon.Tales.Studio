# Argentis через HTTP — одна сцена

07.11.2026. Прототип открывает первый клип с назначенным дублем и двумя доступными видео. При запуске можно указать ID сегмента. «Следующий дубль» меняет видео предпросмотра. Обрезка доступна для дубля, назначенного клипу. «Начало по кадру» включает показанный кадр, а «Конец после кадра» оставляет его последним в участке.

Для предпросмотра FFmpeg читает один кадр по HTTP из `/api/media`. «Сохранить обрезку» посылает `edit_clip_source` с ревизией проекта в действующий Python API. «Открыть заново» перечитывает проект и показывает первый кадр сохранённого участка. [Контракт API](../API.md).

## Повтор проверки

Сборка из корня Studio на Windows. Текущая версия пакетов — `0.2.5.1-alpha`,
локальный feed находится в `src/.local/truemoon-feed`. Первоначальная проверка
ниже использовала снимок `0.2.2.7-alpha.ui.20261107100039380`; обновление пакетов
проверено отдельно. [Подготовка нового feed и ограничения](../src/README.md).

```powershell
Push-Location src
# Только при первом заполнении локального feed из подтверждённого checkout:
# ./Update-TrueMoonPackages.ps1 -FrameworkRoot ../../TrueMoon
dotnet restore TrueMoon.Tales.Studio.slnx --configfile NuGet.Config --packages .local/studio-packages --artifacts-path .local/studio-build '-bl:.local/studio-restore-{}.binlog'
dotnet build TrueMoon.Tales.Studio.slnx --no-restore --artifacts-path .local/studio-build '-bl:.local/studio-debug-{}.binlog'
Pop-Location
```

В отдельном терминале из корня Studio запустите проверочную сцену существующим Python из среды Studio. Скрипт создаёт исходный проект и его копию в новом каталоге `.local/argentis-qa-*`, затем публикует копию на свободном loopback-порту. Он печатает адрес и путь к FFmpeg.

```powershell
& 'E:/ComfyUI_windows_portable/python_embeded/python.exe' -s -B Verification/Argentis.Prototype.py
```

В первом терминале подставьте адрес и путь из вывода скрипта.

```powershell
& 'src/.local/studio-build/bin/TrueMoon.Tales.Studio/debug/TrueMoon.Tales.Studio.exe' 'http://127.0.0.1:<порт>' argentis-qa '<путь к ffmpeg.exe>'
```

## Результат первоначальной проверки

- Сборка Debug прошла с 0 предупреждений и 0 ошибок. Пять HTTP-тестов таймлайна прошли.
- В окне Argentis оба дубля показали кадры `00 → 01`. Для дубля A также подтверждены `01 → 02` и обратный шаг `01 → 00` по номерам внутри видео.
- У клипа QA-01 выставлены начало на кадре 01 и конец после кадра 02. HTTP вернул 200, ревизия выросла с 3 до 4, интервал стал `[1, 3)` и длина сократилась с 8 до 2 кадров. «Открыть заново» показало тот же участок, ревизию 4 и кадр 01.
- В JSON на диске сохранены ID клипа, дубль A, позиция клипа и 12-кадровое окно сцены. Снимок истории ревизии 3 совпал с исходным проектом побайтно. SHA-256 обоих MP4 совпали. Каталог заданий отсутствует.

Проверенный медиапрофиль — MP4 с постоянной частотой 24 кадра/с. Для каждого шага запускается отдельный FFmpeg. Отзывчивость длинной шкалы, непрерывное воспроизведение и переменная частота кадров требуют отдельной проверки.
