# Контекстное меню таймлайна — Studio 0.11

Нажмите **правой кнопкой** на блок или полосу сегмента. С клавиатуры: выберите элемент фокусом и нажмите **Shift+F10** либо клавишу **Menu**.

Открытие выбирает элемент и приостанавливает просмотр, сохраняя положение курсора. Курсор не переносится в точку правого клика. Меню помещается в границы окна; навигация — ↑/↓, Home/End, Enter/Space. **Escape** закрывает его и возвращает фокус на элемент, Tab выводит из меню. Щелчок снаружи, прокрутка таймлайна, изменение окна или перерисовка проекта закрывают меню.

## Блок

- **Участок и скорость** — прежний редактор выбранного дубля; для заглушки недоступен.
- **Описание и время** — сценарная карточка этого использования блока.
- **Материалы и промпт** — исходный библиотечный блок. Его постановка может использоваться в нескольких местах монтажа.
- **К началу блока** — поставить курсор на его начало.
- **Разрезать по курсору** — прежняя операция split; доступна строго внутри блока. На границах и вне блока отключена.
- **Закрепить начало**, **Защитить паузу** — переключатели с отметкой текущего состояния.
- **Убрать блок из монтажа** — удалить только монтажное использование, сохранив исходник и дубли.

## Сегмент

**Открыть сегмент**, **Описание и время**, **Просмотреть сегмент**, **К началу сегмента**, **Добавить блок**, **Добавить звук**, **Убрать промежутки**, **Убрать сегмент из сценария** используют те же формы и действия, что карточка/панель таймлайна. Удаление сегмента убирает его монтажные блоки и звуковые события; файлы/библиотека сохраняются, отмена возвращает всю структуру.

Меню не создаёт отдельную историю: изменения проходят через прежние API и **↶ / ↷**. При сохранении команды недоступны; если проект/версия/элемент изменились после открытия, старое действие отклоняется. Само открытие меню не записывает проект и не запускает генерацию.

## Стык — Studio 0.13

Значок ◇/◆ на границе соседних блоков открывает меню стыка (правый/левый клик, Shift+F10/Menu, Enter/Space). **«Переход через чёрный»** задаёт затемнение/паузу/появление; **«Убрать переход»** снимает эффект; **«К началу следующего блока»** перемещает только курсор.
