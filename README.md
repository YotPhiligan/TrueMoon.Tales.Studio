# True Moon Studio

Локальная студия видеопродакшена для Windows. В ней можно связать текст со
сценарием, собрать раскадровку и аниматик, подобрать дубли, смонтировать видео
со звуком и экспортировать MP4. В репозитории находятся приложение, локальный
API и CLI, а также интеграция с ComfyUI.

## Возможности

- **Сценарий и материалы.** Привязывайте сегменты и действия к версии главы,
  добавляйте источники и дубли, сохраняйте версии эталонов и замечания к кадрам.
  [Экран сценария](Scenario.md#studio-screenplay)
- **Раскадровка и аниматик.** Переходите от плана к действию или кадру на шкале,
  сравнивайте соседние планы и сцены, просматривайте всю шкалу с готовым видео,
  опорными кадрами и временным звуком. [Раскадровка и просмотр](SegmentPreview.md#studio-storyboard)
- **Монтаж и экспорт.** Перемещайте, обрезайте и разрезайте клипы, настраивайте
  звук, титры и переходы. Список проблем ведёт к клипу или ассету. Можно
  просмотреть диапазон или экспортировать сохранённый монтаж в MP4 на CPU.
  [Рабочее окно](src/WindowDesign.md#workspace-export). Для продолжения монтажа
  во внешнем редакторе доступен [экспорт XML](src/WindowDesign.md#workspace-interchange).
- **Генерация по черновику.** Используйте выбранный черновик для подготовки графа Omni.v2,
  проверьте входы и запустите отдельное задание. Studio сохраняет готовый
  MP4 в `video/` проекта и добавляет дубль с привязкой к черновику.
  [Порядок работы](src/WindowDesign.md#studio-full-transfer-prepare) · [Текущая приёмка](Status.md#studio-full-transfer-run)

## Запуск

Для настольного EXE нужны .NET 11 и ASP.NET Core Runtime 11. Для сборки из исходников используйте SDK и локальный набор пакетов TrueMoon. [Подготовка пакетов](src/README.md#пакеты-truemoon) · [Сборка](src/README.md#сборка)

```powershell
.\TrueMoon.Tales.Studio.exe
```

Без аргументов Studio показывает недавние и доступные проекты. В пустом рабочем пространстве она создаёт «Без названия» и открывает редактор с пустым таймлайном. Если проект некуда сохранить, экран «Проекты» покажет причину. [Экран «Проекты»](src/README.md#projects)

Список, просмотр и редактор переключаются в одном окне. Кнопка «К проектам» возвращает к списку. Для старого проекта с правом записи просмотр предлагает «Обновить формат и открыть редактор».

EXE и `Start-Studio.cmd` по умолчанию используют `%LOCALAPPDATA%\TrueMoon.Tales\Studio\config.json`. EXE создаёт профиль при первом запуске, если профиля в AppData ещё нет. Другой профиль можно выбрать через `TRUE_MOON_STUDIO_CONFIG` или `--projects --config <файл>`. На экране «Проекты» команда «Открыть существующий проект» принимает полный путь к папке или файлу `.studio` в одном из разрешённых корней. [Пример конфигурации](Studio.config.example.json) · [Расположение профиля и перенос](Workspace.md#настройка-и-запуск)

Для кадров, воспроизведения, рабочего просмотра и CPU-экспорта schema2 укажите
`ffmpeg_executable` и `ffprobe_executable` или добавьте инструменты в `PATH`.
Для экспорта настройте отдельный `exports_root`. Python нужен для Web и
запуска генерации в ComfyUI. [Настройка медиа](Workspace.md#backend-media-tools--17112026) ·
[Настройка экспорта](src/Verification/BackendExport.md#настройка)

Генерация по черновику использует установленный ComfyUI и веса Omni.v2.
Studio готовит граф на C# с FFprobe. Генерацию запускает отдельная команда
в библиотеке. [Настройка генерации](Workspace.md#workspace-full-transfer)

### Веб-интерфейс и автоматизация

Для проектов schema 1 используйте Python/Web. Из корня репозитория запустите `Start-Studio.cmd` с PowerShell 7 и настроенным `python_executable`. Браузер откроется по адресу `http://127.0.0.1:8787`. Для schema 2 настольная Studio предоставляет собственный локальный HTTP API и CLI. [Веб-запуск](Workspace.md#настройка-и-запуск) · [API и CLI](API.md)

## Данные и восстановление

- Новый проект хранится в `Project.studio`, обычном JSON. Studio также читает именные `.studio` и прежние `Studio.project.json`. В папке допустим один файл проекта. История хранится в `Production/History/`. Для настольного редактирования нужны schema 2 и разрешение на запись папки в `project_write_roots`. [Модель проекта](ProjectModel.md) · [Хранилище](src/ProjectStore.md)
- Проекты и медиа хранятся отдельно от кода. В рабочей области TrueMoon видеопроекты находятся в Videos, референсы — в Arts, главы и лор — в Texts и Lore. Подключайте их через настроенные корни и пути вида `@videos/…`. Состояние, кэш и экспорты используют отдельные каталоги. [Каталоги и совместимость путей](Workspace.md)
- Снимки заданий генерации по черновику лежат в `.local/`, рабочие файлы в Temp, готовые дубли в `video/`. [Генерация в Studio](src/WindowDesign.md#studio-full-transfer-run) · [Сбор результатов Python/Web](API.md#генерация--отдельные-действия)
- Сохранённый эпизод schema2 можно упаковать вместе с историей и материалами и восстановить в отдельную копию. [Архив и восстановление](API.md#episode-archive)
