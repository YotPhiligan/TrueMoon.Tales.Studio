# True Moon Studio 0.15

**M2 выполнен: активный код находится в `E:/source/my/TrueMoon.Tales/TrueMoon.Tales.Studio`.**
Студия видеопродакшена включает UI, API/CLI, тесты и общую интеграцию ComfyUI.
Данные Клэр и опенинга пока подключены из Book. Новые проекты создаются в Videos;
Arts/Lore/Texts подключаются как внешние библиотеки. ID и связи существующих
проектов сохранены без переписывания их JSON.

Запуск: [Start-Studio.cmd](Start-Studio.cmd). Пути и Python задаются в
`Studio.config.local.json`; [настройка каталогов и миграция](Workspace.md).
Состояние, кэш и новые экспорты вынесены из репозитория кода. Порт занятого
экземпляра не перехватывается. При переходе со старой версии остановить её сервер.

Дважды открыть [Start-Studio.cmd](Start-Studio.cmd). Используется Python из `Studio.config.local.json`; установка пакетов и сборка фронтенда не требуются. Откроется `http://127.0.0.1:8787`. Окно командной строки оставлять открытым; Ctrl+C останавливает UI. Если порт занят, новый экземпляр сообщает ошибку; существующий сервер продолжает работу.

Приложение слушает только локальный адрес. Его запуск не включает ComfyUI и не загружает видеомодель. Команда вручную из корня репозитория Studio:

```powershell
& 'E:/ComfyUI_windows_portable/python_embeded/python.exe' -s -B ./app.py --port 8787 --open-browser
```

На этой машине используются уже установленные `psutil`, PyAV, Pillow, NumPy, `imageio-ffmpeg` (для экспорта MP4) и **PowerShell 7**. Для ограниченного запуска UI ищет `pwsh` в PATH, затем `Program Files/PowerShell/7/pwsh.exe`; отсутствие обнаруживается до подготовки задания. Windows PowerShell 5.1 для этой обвязки не используется: при перенаправлении логов он может вернуть пустой ExitCode после timed wait. Другой компьютер потребует настройки путей portable Python/ядра и моделей. Порт 8787 можно изменить аргументом `--port`.

## Первый проход

1. Выбрать проект и составить сценарные сегменты/блоки либо открыть уже существующий монтаж. Карточка сегмента показывает описания и время; «Материалы и промпт» открывает исходный редактор блока. Прежние исследования доступны через «Библиотека исходников», импортированные дубли требуют просмотра.
2. Во вкладке «Референсы» проверить изображения, роли и порядок Picture; во вкладке «Опорные кадры» — первый/последний/промежуточные кадры. Перестановка изображений согласованно перенумеровывает `<Picture N>`; привязки Guides сохраняются. В обеих вкладках доступны загрузка и перетаскивание; загрузка обычного референса сама не назначает Guide.
3. В «Постановке» выбрать новый план или Motion Context, размер, длительность источника и seed. Монтажное окно хранится отдельно: оно не ускоряет видео. Промпт доступен шестью разделами и целиком. Правки сохраняются автоматически, также работает Ctrl+S.
4. «Проверить» проверяет входы, метки, Guides, сетку времени и размер native AV. Это техническая проверка; художественную связность оценивает автор/агент.
5. «Подготовить» сохраняет снимок задания и собирает API/UI-граф без очереди и копирования в ComfyUI input. Только отдельное «Запустить 1 дубль» начинает staging и ограниченный запуск. Изменённые после подготовки материалы требуют новой подготовки.
6. В «Дублях» просмотреть результат, записать замечания, отобрать/принять, сравнить два видео. «Продолжить» создаёт черновик с точными native AV-latent и последним PNG; следующую фазу действия нужно отредактировать отдельно. Создание продолжения не запускает генерацию.

Интеграция использует [Omni.v1.1](Workflows/Omni.v1.1/README.md): guided и native AV/Motion Context, 896×512 или 1280×736, 24 fps. Для текущего профиля запрошенные 2 с дают 56 кадров / 2,333 с; продолжение удаляет 22 контекстных кадра и оставляет 34 / 1,417 с нового видео. Это параметры профиля, а не универсальная формула видеомоделей.

## Данные и восстановление

- Состояние каждого ролика — `Production/Studio.project.json`, история предыдущих версий — `Production/History/`. Новые проекты создаются в `AMV/Projects/`.
- Задания — `Production/Jobs/job-…/`: входной снимок, точные хэши, Preview, затем Run/collect при явном запуске. Загруженные изображения/видео/аудио — `Production/Imports/` под уникальными именами.
- `state_root/Registry.json` содержит локальный список проектов. При M2 прежний реестр подключается явным `--adopt-registry`; автоматического импорта при старте нет. Настройки каталогов и совместимости — в [Workspace.md](Workspace.md).
- Исходные карточки Markdown, арты и архивные дубли читаются на месте. Изменение блока в UI пока не переписывает его исходную Markdown-карточку; она доступна кнопкой «Карточка блока». Неизвестные монтажные окна остаются пустыми.
- Версия проекта проверяется перед записью. Конфликт возвращает 409 и предлагает явный выбор сохранённой/своей правки; молчаливого затирания нет. История восстанавливает редактируемые поля блока, сохраняя дубли.
- Подготовленное задание можно отправить один раз. Одновременно допускается один принадлежащий приложению запуск. После перезапуска приложение наблюдает существующее задание, не отправляя его повторно.
- Ограничители ядра: CPU-проверка 90 с, запуск сервера 90 с, генерация 480 с, отсутствие прогресса 180 с, итоговый предел 720 с и независимый watchdog; UI имеет дополнительный внешний предел 900 с. Остановка проверяет PID, время создания, исполняемый файл и команду принадлежащих заданию процессов. Закрытие окна UI не заменяет команду остановки задания; watchdog продолжает ограничивать собственный сервер.

## Совместная работа с ИИ

Вкладка «ИИ» создаёт локальные задания в режиме предложения или указанной правки. Их можно передать в чат, взять через [studio_agent.py](studio_agent.py), записать результат и наблюдать статус в UI. Расширенный контекст включает brief, исходные документы с SHA256/обрезкой, референсы, дубли, монтаж и фактических соседей. Внешний агент использует тот же [HTTP API](API.md), что и UI, с `expected_revision` и `actor`. Для задания и проекта действуют отдельные версии. Обработка самих изображений зависит от возможностей агента; путь не означает выполненный просмотр.

Встроенного LLM, автоматической отправки заданий в чат и MCP-сервера пока нет. Переходы, титры и финальная сборка с эффектами и расширенным звуком, Full Transfer через Video 1, пакетные запуски и функции адаптации глав остаются в [плане](Plan.md). Черновой экспорт 0.9 проверен на совпадение участков, скорости, пауз и музыкального времени с сеткой предпросмотра; задержки живого браузерного декодирования и потери кодеков сохраняются. Пониженный размер генерации доступен как отдельный профиль; повторная генерация большого размера не обещает тот же рисунок движения.

## M4 · Book отключён

Видео/Production/исследования находятся в TrueMoon.Tales.Videos. Конфигурация
`legacy_read_enabled: false` оставляет legacy_root только логическим пространством
старых имён: стат/чтение/запись туда запрещены, unmapped пути возвращают 403.

Новые prepare/launch работают с новыми физическими путями. Исторические снимки
не переписываются. Для применения конфигурации перезапустить Studio.
