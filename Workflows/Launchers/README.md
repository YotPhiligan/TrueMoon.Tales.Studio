# Запуск ComfyUI для видеопроизводства

27.10.2026. Отдельный запуск выбран по запросу автора после R-00.

Рабочая копия: `E:/ComfyUI_windows_portable/run_nvidia_gpu_video_sage.bat`. Файл рядом с этим README — сохранённый исходник для копирования в корень portable; запускать его непосредственно из каталога книги не следует, так как пути Python и main.py определяются относительно самого .bat.

## Профили

| Запуск из E:/ComfyUI_windows_portable | Назначение | Параметры |
|---|---|---|
| run_nvidia_gpu_video_sage.bat | основной вход для видеосессии с Sage | --windows-standalone-build --fast fp16_accumulation --use-sage-attention |
| run_nvidia_gpu_fast_fp16_accumulation.bat | привычный запуск и контрольный вариант | --windows-standalone-build --fast fp16_accumulation |

Новый профиль наследует ровно тот fast-режим, которым уже пользуется автор, и добавляет явный выбор Sage. Не заменять `--fast fp16_accumulation` на голый `--fast`: в текущем cli_args это включает все fast-опции, а не только FP16 accumulation.

Настройки памяти остаются штатными, включая dynamic VRAM. Опция `--disable-dynamic-vram` из изолированного R-00 не перенесена в этот профиль: её влияние надо сравнивать отдельно. Короткие успешные H3-тесты R-00 выполнялись без dynamic VRAM и без fast fp16_accumulation, поэтому вся комбинация нового запуска ещё не прошла производственную приёмку на рабочем клипе. Проверка параметров запуска не заменяет такой тест.

Дополнительная проверка от 27.10: [Omni NVFP4 Run01](../../Research/Results/R-02.T01.OmniNVFP4.Run01/Report.md) успешно выполнен с этими тремя параметрами, 1280 × 736, 56 кадров и 8 шагов. Подтверждены 400 успешных Sage без SDPA внутри H3, dynamic VRAM работает, OOM не было. Это один технический контроль; динамика самого дубля не принята, общего сравнения скорости/качества ещё нет.

## Как пользоваться

1. Завершить текущую очередь и закрыть работающий процесс ComfyUI.
2. Запустить `E:/ComfyUI_windows_portable/run_nvidia_gpu_video_sage.bat`.
3. При старте в консоли должна появиться строка `Using sage attention`. Для возврата к контрольному backend закрыть этот процесс и запустить прежний .bat.

Используется тот же адрес интерфейса, та же установка, модели, custom nodes и пользовательские workflow. Это альтернативный способ запуска одного экземпляра; второй параллельный экземпляр на том же порту не требуется. Уже работающий процесс не меняет backend от появления нового .bat.

Sage выбирается глобально для этой ComfyUI-сессии, а не исключительно для H3. Узлы конкретного графа могут переопределить backend. В текущем native Model Attention Backend нет варианта Sage; явный PyTorch в таком узле может отменить глобальный выбор. В CL-002T01.Ref2VA.v1.json такого узла нет.

`Using sage attention` подтверждает выбор, но не отсутствие fallback на всех вычислениях. В R-00 фактические H3-вызовы были проверены счётчиками; при дальнейшем сравнении воспроизводить этот уровень проверки, если возникнут сомнения в dispatch.

## Проверка и статус

- Исходный fast-launcher сохранён без изменений.
- Аргументы нового запуска проверены portable-парсером установленной ComfyUI: Sage=True, fast только fp16_accumulation, dynamic VRAM=True.
- .bat использует собственный каталог через `%~dp0`, поэтому не зависит от текущей папки вызывающей оболочки; пути заключены в кавычки.
- Дополнительные аргументы `%*` передаются ComfyUI для разовых запусков. Проверка через `--help` позволяет проверить установленный CLI без запуска сервера.
- Рабочая копия действительно выполнена с `--help` из другой папки: exit code 0, сервер не запускался. [Проверка](Validation.json), [вывод CLI](CLI.Help.txt), [хэши копии и исходного launcher](Deployment.json).
- Производственная скорость и качество полного видео остаются открытыми в [R-00](../../Research/Results/R-00.Sage.Portable.v2/Report.md). Штатный режим памяти и FP16 accumulation нельзя считать проверенными только по уменьшенной диагностике Sage.

Источник поддержки Sage: [официальный гайд ComfyUI H3](https://docs.comfy.org/tutorials/video/minimax/minimax-h3#speeding-up-generation-with-sage-attention); точные параметры сверены с установленным `comfy/cli_args.py`.
