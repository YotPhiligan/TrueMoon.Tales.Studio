# Работа над TrueMoon Tales Studio

Назначение: приложение видеопродакшена, локальный API/CLI, UI, тесты и общая
интеграция ComfyUI. [README](README.md), [общие инструкции](../TrueMoon.Workspace/Guidelines.md),
[план переноса](../TrueMoon.Workspace/MIGRATION.md).

В этом репозитории находится активный код Studio 0.15 после M2. Перед технической
задачей читать [README](README.md), [Workspace](Workspace.md),
[Architecture](Architecture.md), [Plan](Plan.md), API и нужный проверочный отчёт.
Старая UI 0.14 в Book сохранена как исходный архив; новые правки кода выполняются
только здесь. Проекты Клэр/опенинга перенесены в Videos в M4.

Соседний `TrueMoon` развивается параллельно: в миграционных задачах не перемещать,
не копировать, не исправлять и не восстанавливать его файлы. Проверять Git только
чтением с `--no-optional-locks`; изменения другой работы не считать поломкой.
Studio исключает этот каталог из доступа через resolver.

- Сохранять разделение кода и пользовательских данных: проекты — Videos,
  общие референсы — Arts, тексты/лор — внешние источники, runtime state/cache отдельно.
- При поддержке внешних корней сохранять allowlist путей, ограничение записи,
  expected_revision, атомарное сохранение, историю и защиту конфликтного черновика.
- Перенос сохраняет существующие ID/связи/тайминги и immutable снимки. Не менять
  авторские проекты/генерации, чтобы упростить тест или получить чистый Git.
- Подготовка workflow не отправляет очередь; чтение/запуск UI не запускают GPU.
  Prepare/launch/collect, таймеры/watchdog, проверка владения процессами и
  восстановление без повторной отправки сохраняются.
- Изменения preview/монтажа проверять с учётом соответствия CPU MP4: участки,
  скорости, звук, переходы, кириллица/титры. Использовать отдельный тестовый проект.
- GPU, длительные/аппаратные проверки и установка моделей требуют соответствующего
  запроса; не занимать чужие порты/очереди и не закрывать пользовательские процессы.
- Тесты/синтаксис/ссылки выбирать по изменению. Старые отчёты описывают прошлую
  конфигурацию, а не доказывают работоспособность после переноса.
- Обновлять фактические статусы/документацию. Код остаётся Python/JS до отдельного
  технического решения; наличие C# фреймворка не является миграцией реализации.

## M4 · Book отключён

Видео/Production/исследования находятся в TrueMoon.Tales.Videos. Конфигурация
`legacy_read_enabled: false` оставляет legacy_root только логическим пространством
старых имён: стат/чтение/запись туда запрещены, unmapped пути возвращают 403.
Aliases перенаправляют относительные и абсолютные старые строки до файлового IO.
Экспорт получает только реальные новые пути. Исторический prepared с config в старом
пространстве имён возвращает 409 без запуска/мутации; подготовить свежий дубль.
Новые prepare/launch работают с новыми физическими путями. Исторические снимки
не переписываются. Для применения конфигурации перезапустить Studio.


## Arts · категории в корне

Библиотека TrueMoon.Tales.Arts использует Characters/, Props/ и другие категории
сразу в корне. Mount @arts указывает на корень репозитория; пример нового адреса:
@arts/Characters/Claire/ComfyUI_00915_.png. Конфигурация сохраняет aliases для
старого @arts/Arts/... и прежнего Book/Arts/... без переписывания ID/истории.
После обновления Studio.config.local.json перезапустить уже открытый сервер Studio.
